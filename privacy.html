Politique de Confidentialité

Dernière mise à jour : Mai 2026

Introduction
Bienvenue sur Day Market. Nous nous engageons à protéger votre vie privée et vos données personnelles. Cette politique de confidentialité explique comment nous collectons, utilisons et protégeons vos informations lorsque vous utilisez notre application et notre site web.
En utilisant Day Market, vous acceptez les pratiques décrites dans cette politique. Si vous n'acceptez pas ces termes, veuillez ne pas utiliser notre application.
Données collectées
Nous collectons les données suivantes pour faire fonctionner l'application :
  • Données de compte : adresse email, nom d'utilisateur, mot de passe chiffré
  • Données de trading : trades journalisés, statistiques, performances, stratégies
  • Données d'utilisation : fonctionnalités utilisées, fréquence de connexion
  • Données techniques : type d'appareil, version iOS, identifiants anonymisés
  • Données de paiement : gérées exclusivement par Apple App Store — nous ne stockons jamais vos données bancaires
Utilisation des données
Vos données sont utilisées uniquement pour :
  • Faire fonctionner et améliorer l'application Day Market
  • Personnaliser votre expérience de trading
  • Générer vos statistiques et analyses de performance
  • Vous envoyer des notifications pertinentes (si activées)
  • Assurer la sécurité de votre compte
  • Respecter nos obligations légales
Nous ne vendons jamais vos données à des tiers. Nous ne les utilisons pas à des fins publicitaires.
Sécurité des données
La sécurité de vos données est notre priorité absolue :
  • Chiffrement en transit : toutes les communications utilisent HTTPS/TLS
  • Chiffrement au repos : vos données sont chiffrées avec AES-256
  • Mots de passe : hashés avec bcrypt — jamais stockés en clair
  • Authentification : tokens JWT sécurisés avec expiration automatique
  • Accès : chaque utilisateur ne peut accéder qu'à ses propres données
Vos droits RGPD
Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :
  • Droit d'accès : consulter toutes vos données personnelles
  • Droit de rectification : corriger vos données inexactes
  • Droit à l'effacement : supprimer votre compte et toutes vos données
  • Droit à la portabilité : exporter vos données en format JSON
  • Droit d'opposition : vous opposer au traitement de vos données
Vous pouvez exercer tous ces droits directement depuis l'application dans Paramètres → Mon Compte, ou en nous contactant à support.daymarket@gmail.com
Cookies et analytics
Nous utilisons des analytics anonymisés pour comprendre comment l'application est utilisée et l'améliorer. Ces données ne permettent pas de vous identifier personnellement. Nous n'utilisons aucun cookie publicitaire ou de tracking tiers.
Services tiers
Day Market utilise les services tiers suivants, chacun avec leur propre politique de confidentialité :
  • RevenueCat : gestion des abonnements
  • Expo / EAS : infrastructure de l'application
  • Resend : envoi d'emails transactionnels
Suppression des données
Vous pouvez supprimer votre compte à tout moment depuis l'application. Toutes vos données personnelles seront définitivement supprimées dans un délai de 30 jours. Cette action est irréversible.
Contact
Pour toute question concernant cette politique de confidentialité ou vos données personnelles, contactez-nous :
📧 support.daymarket@gmail.com
🌐 daymarketstore.netlify.app
Nous répondons en moins de 48h ouvrées.
